========================================
  酒店房价采集工具 · 使用说明
  （个人分析专用 · 请勿商用）
========================================

【发给你的是什么】
解压即用的 Windows 程序，无需安装 Python。


【电脑要求】
- Windows 10 / 11（64 位）
- 能正常上网
- 杀毒软件若拦截，请选择「允许」或加入白名单


【第一次使用】

1. 解压 zip 到任意文件夹
   （路径尽量不要含特殊符号，不要放在仅云同步的目录）

2. 双击 hotel-analyzer.exe
   （也可双击 start.bat）

3. 勾选底部「我已阅读并同意免责声明」
   —— 不勾选则无法使用任何功能

4. 点击「登录」
   - 会弹出浏览器窗口
   - 用【你自己的】账号扫码或验证码登录
   - 登录成功后窗口会自动关闭


【日常使用】

1. 双击 hotel-analyzer.exe

2. 确认已勾选免责声明

3. 推荐点「一条龙」（采集 + 分析 + 导出）
   - 城市：例如 上海
   - 关键词：可填具体酒店名；不填则按城市列表采集
   - 入住开始 / 结束：必须是【今天及以后】
   - 有头模式：一般不勾；总失败时可勾上，方便过验证码
   - 强制重采：第一次可勾；之后同一日期可不勾（跳过已采）

4. 导出的 Excel 在：
     输出\excel\今天的日期\
   用 Excel / WPS 打开即可


【界面按钮说明】

  登录          首次必做；登录过期时再点一次
  一条龙        采集 + 分析 + 导出（最常用）
  采集          只采集，不导出
  分析          只看库内统计
  导出 Excel    只导出，不采集
  打开导出目录  直接打开今天的 Excel 文件夹


【常见问题】

Q：双击没反应 / 被杀毒软件删了？
A：到杀毒软件「隔离区」恢复，并加入白名单后再打开。

Q：提示需要登录 / 登录失效？
A：再点一次「登录」，重新扫码即可。

Q：采不到房型或出现验证码？
A：勾选「有头模式」再采；在弹出的浏览器里手动完成验证后继续。

Q：为什么不能查昨天的房价？
A：只能查今天及以后的可订日期，无法回填历史。

Q：结果存在哪？
A：Excel → 输出\excel\日期\
   数据库 → data\（一般不用手动打开）

Q：文件夹里的 _internal、browsers 能删吗？
A：不能删。删了程序无法运行。
