========================================
  携程酒店房价采集工具 · 使用说明
  （个人非商用，仅供自己分析）
========================================

【电脑要求】
- Windows 10/11
- 已安装 Python 3.10+（安装时勾选 Add python.exe to PATH）
  下载：https://www.python.org/downloads/


【第一次使用：只需做一次】

1. 解压本文件夹到任意位置（路径尽量不要含特殊符号）

2. 双击「一键安装.bat」（也可双击 setup.bat）
   - 等待依赖和浏览器装完（可能几分钟）
   - 看到 Setup OK / Press any key 即可
   - 若窗口一闪就关：请改双击同目录下的 setup.bat

3. 双击「启动.bat」（也可双击 start.bat）
   - 出现数字菜单

4. 输入 1 回车 → 登录携程
   - 会弹出浏览器窗口
   - 用【你自己的】携程账号扫码或验证码登录
   - 登录成功后窗口会自动关闭


【日常使用】

1. 双击「启动.bat」

2. 推荐选 6（一条龙：采集 + 分析 + 导出）
   - 城市：例如 上海
   - 酒店关键词：可填具体酒店名；直接回车=采该城市列表
   - 开始/结束日期：必须是【今天及以后】（不能查昨天及更早）
   - 有头模式：一般选 N；若总失败可改 Y 观察页面
   - 强制重采：第一次选 Y；以后同一日期可跳过
   - 仅采列表页首推：选 N = 进详情页采全部房型（更全、更慢）

3. 导出的 Excel 在：
     输出\excel\今天的日期\
   用 Excel / WPS 打开即可


【菜单速查】

  1  登录携程（首次必做，登录过期时再做）
  2  只采集某个城市（可设日期范围）
  3  批量采集多个城市
  4  只看统计分析
  5  只导出 Excel
  6  采集 + 分析 + 导出（最常用）
  0  退出


【常见问题】

Q：提示未找到 Python？
A：安装 Python 并勾选 Add to PATH，然后重新开一个命令窗口再试。

Q：提示需要登录 / 登录态失效？
A：启动后选菜单 1，重新登录一次。

Q：采不到房型或触发验证码？
A：稍后再试；或采集时选「有头模式 Y」，在浏览器里手动过验证码。

Q：为什么不能查昨天的房价？
A：只能查今天及以后的可订日期；昨天及更早无法回填。

Q：结果存在哪？
A：Excel → 输出\excel\日期\
   数据库 → data\hotel_prices.db（一般不用手动打开）


【重要提醒】

1. 请使用你自己的携程账号，不要用别人的登录态文件
2. 不要把 data\ctrip_state.json 发给别人（里面有登录信息）
3. 仅个人分析使用，请勿商用或二次分发数据
4. 采集请保持默认间隔，不要改太频繁


有问题先看本说明；仍不行再找发给你的人帮忙。
