========================================
  酒店房价采集工具 · 使用说明
  （个人分析专用 · 请勿商用）
========================================

【发给你的是什么】
解压即用的 Windows 程序，无需安装 Python。


【电脑要求】
- Windows 10 / 11（64 位）
- 能正常上网
- 杀毒软件若拦截，请选择「允许」或加入白名单


【第一次使用】

1. 解压 zip 到任意文件夹
   （路径尽量不要含特殊符号，不要放在仅云同步的目录）

2. 双击 hotel-analyzer.exe
   （也可双击 start.bat）

3. 勾选底部「我已阅读并同意免责声明」
   —— 不勾选则无法使用任何功能

4. 点击「登录」
   - 会弹出浏览器窗口
   - 用【你自己的】账号扫码或验证码登录
   - 登录成功后窗口会自动关闭


【日常使用】

1. 双击 hotel-analyzer.exe

2. 确认已勾选免责声明

3. 推荐点「一条龙」（采集 + 分析 + 导出）
   - 城市：例如 上海
   - 指定酒店：一行一个酒店全名（或用逗号分隔）；留空则采该城市列表前若干家
     示例：
       上海外滩W酒店
       上海浦东丽思卡尔顿酒店
       上海和平饭店
   - 入住开始 / 结束：必须是【今天及以后】
   - 有头模式：一般不勾；总失败时可勾上，方便过验证码
   - 强制重采：第一次可勾；之后同一日期可不勾（跳过已采）

4. 导出的 Excel 在：
     输出\excel\今天的日期\
   每次导出会生成两个文件：
   - 分析表（明细按「时段×有无早餐」分 Sheet，如 明细_10点_有早餐 / 明细_10点_无早餐；另有汇总 / 趋势图 / 波动率）
   - 业务汇总表（文件名带「_业务汇总」；有早餐 / 无早餐 各一个 Sheet，Sheet 内仍按酒店×房型×日期×时段矩阵；综合门市价为每日均价，流量与红色标记需人工填写）
   用 Excel / WPS 打开即可


【界面按钮说明】

  登录          首次必做；登录过期时再点一次
  一条龙        采集 + 分析 + 导出（最常用）
  采集          只采集，不导出
  分析          只看库内统计
  导出 Excel    只导出，不采集
  定时任务      配置多时段自动「一条龙」（采集+分析+导出，见下方）
  打开导出目录  直接打开今天的 Excel 文件夹


【定时任务怎么用】

1. 先完成「登录」，并勾选免责声明
2. 点击「定时任务」→ 新建任务：
   - 填城市、酒店（一行一个）
   - 日期：滚动（今天起 N 天）或固定区间
   - 触发时刻：可添加多个，如 10:00、14:00、18:00（不限死）
   - 选择星期、是否强制重采、无头模式
3. 保存任务后，打开窗口底部「启动调度」
4. 程序需保持运行（可最小化）；到点会自动「一条龙」：采集 → 分析 → 导出 Excel
5. 不会补跑已错过的时刻；关机/休眠期间不会触发
6. 关闭主程序会停止调度


【常见问题】

Q：双击没反应 / 被杀毒软件删了？
A：到杀毒软件「隔离区」恢复，并加入白名单后再打开。

Q：提示需要登录 / 登录失效？
A：再点一次「登录」，重新扫码即可。

Q：采不到房型或出现验证码？
A：勾选「有头模式」再采；在弹出的浏览器里手动完成验证后继续。

Q：为什么不能查昨天的房价？
A：只能查今天及以后的可订日期，无法回填历史。

Q：结果存在哪？
A：Excel → 输出\excel\日期\
   数据库 → data\（一般不用手动打开）

Q：文件夹里的 _internal、browsers 能删吗？
A：不能删。删了程序无法运行。
